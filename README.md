# MOMO 桌面宠物界面原型

面向安卓与电脑的响应式 Web 原型，使用 Three.js + Vite。不是安卓 APK 或原生桌面应用。

## 运行

```sh
npm ci --cache /workspace/.npm-cache
npm run dev
```

生产构建：`npm run build`；构建预览：`npm run preview`。

## 已实现

- 程序化 3D 云朵精灵、旋转缩放、摸头/喂食/休息交互与三种配色。
- 主页、伙伴图鉴、聊天演示、任务占位页、偏好设置。
- 本地导入自包含 GLB/GLTF，自动归一化大小并播放模型自带动画。限制 100 MB。使用 IndexedDB 保存一份自定义模型，刷新后恢复上次选中的模型；不自动绑定骨骼或重定向动作。
- 照片本地预览；昵称、安静模式、大小使用 localStorage 保存。

## 尚未实现

- 离线 AI 模型权重与推理引擎。聊天为明确标记的预设回复。
- 照片生成 3D。该能力需要独立生成模型/服务。
- 安卓悬浮窗、无障碍操作、后台服务，以及电脑原生透明桌面窗口。
- 淘宝/京东活动自动化、账号与跨设备同步。

后续安卓原生集成建议：角色渲染层 + 原生服务层 + 独立本地推理层。模型权重随安装资源打包时，需要验证许可证、完整性、安装体积、真机内存及温度。不要把页面演示能力视为已具备 AI 或应用操控能力。

## 验证

已执行 JavaScript 语法检查、生产构建与 Chromium 浏览器自动化检查。尚未进行安卓真机或原生安装包验证。

## 0.2 交互更新

- 自动眨眼、睡眠闭眼、互动手臂动作、直接点击角色互动。
- 云端/花园/夜晚氛围和可开关的星星项链（内置角色）。
- 陪伴模式，按 Esc 返回工作台；下载当前渲染画面为透明 PNG。
- 保存配色、场景、配饰、互动次数与首次陪伴日期；本地存储数据异常时回退默认值。
- 自定义模型仅加载内嵌资源，拒绝外部贴图/缓冲区链接。
- 已通过 Chromium 桌面及 412px 手机视口交互检查，包括 WebGL 启动、主题/配色/昵称持久化、互动计数、陪伴模式退出和聊天输入安全。浏览器检查不代表安卓原生能力已实现。


## 0.3 模型管理

- 自定义模型保存在当前浏览器 IndexedDB，可恢复、删除；内置配色与自定义模型的选择会持久化。
- 导出当前角色为自包含 GLB，支持再次导入。内置角色可连同项链导出，自定义角色保留模型自带动画。
- 导入失败保留当前角色；拒绝外部资源链接，只接受自包含模型。
- 浏览器存储受配额与清理策略影响，不代替文件备份；更换设备或浏览器不会同步模型。

## 自动化测试

```sh
npm ci
npx playwright install chromium
npm test
```

已安装系统 Chromium 时可执行 `CHROMIUM_PATH=/usr/bin/chromium npm test`。
测试覆盖模型导入、持久化恢复、GLB 导出再导入、错误恢复、删除，以及手机布局与偏好持久化。
