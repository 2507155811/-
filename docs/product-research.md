## 本轮交付

- 每日签到、互动经验、成长等级与成就，切换外观不影响进度。
- 专注计时、暂停、恢复、刷新续计，完成后记录陪伴进度。
- 待办添加、完成、删除、清理，以及一次性到时提醒。
- 显式授权浏览器通知，可选设备语音；安静模式关闭外部通知与语音。
- 15/30/60 FPS、动态特效开关；页面隐藏或切换到其他页面时不进行 3D 渲染。
- 记忆 JSON 备份、格式验证、恢复前摘要确认、恢复撤销。3D 模型另行导出。
- 生产版离线资源缓存与浏览器安装入口；不等于原生桌面悬浮。

## 平台边界与后续依赖

这仍是 Web 应用，系统通知不是可靠的后台闹钟。关闭页面不会执行计时回调，重新打开会根据时间戳结算；不能承诺息屏或浏览器后台被系统冻结时实时提醒。

离线 AI：目前没有打包权重与推理引擎。候选模型文件下载请求被当前网络代理拒绝（huggingface.co，HTTP CONNECT 403），不能以预设回复替代 AI。需要确定可合法分发的权重、可访问且可信的下载源，并进行推理集成和真机性能验证。

安卓原生：本机未发现 adb、sdkmanager 或 Android SDK；没有生成或验证 APK。安卓悬浮、前台服务、无障碍执行需要独立原生集成和真机权限验证。电脑透明窗口、托盘、鼠标穿透同样需要原生外壳。

照片生成 3D：尚未选定生成引擎/服务，需要独立模型、资源与质量验证；当前只在本地预览照片。

淘宝/京东双 11 自动化：按用户此前要求后续添加，尚未读取活动页，不声称可完成具体活动任务。
