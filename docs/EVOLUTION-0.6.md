# MOMO 0.6

- 默认启动透明桌面宠物；双击打开聊天，悬浮菜单提供进化、专注和偏好设置。
- 新的原创程序化龙系模型：绒角幼兽、赤焰龙仔、角冠暴龙、合金龙卫。参考经典龙系伙伴的成长轮廓，不包含官方或未授权提取的角色模型；未找到可核验并直接获取的开源暴龙兽资产。
- 互动 +1、专注完成 +5、签到 +3；形态解锁要求 0 / 30 / 100 / 240。可预览锁定形态，预览不写入成长进度。已解锁形态可随时切换。
- 进化记录独立保存为 momo-evolution；备份包含此记录。聊天、记事、昵称、待办不随外观或进化而改变。
- 角色几何按关节和材质合并并复用顶点，约 0.8–4.5 万顶点、13–40 次绘制（龙系）；六翼天使约 9.3 万顶点，低于导入预算。共享 128px 程序化鳞片纹理。仍默认 15 FPS，隐藏、息屏、推理时暂停动画。
- Windows 在 Windows 构建机上从固定 llama.cpp 提交编译静态 CPU 引擎，禁用 OpenMP / AVX / AVX2 / FMA / F16C / SSE4.2 / BMI2，减少运行库与 CPU 兼容性问题。实际执行包内引擎和 GGUF 推理后才上传构件。
- 模型加载失败会显示 Windows 退出码对应诊断，并在用户数据目录写入 MOMO-ai-diagnostic.log；不会写入聊天或 API 密钥。没有具体用户报错时，不能断言已定位用户设备故障。
- GitHub Release 上传曾返回 403 Resource not accessible by integration，因此默认通过 Actions Artifacts 分发。登录 GitHub 后，在成功构建页底部下载 momo-windows / momo-android。保留 14 天。Release 仅在手动勾选发布且令牌有权限时执行。

未完成用户设备上的 Windows / Android 实机验证和功耗测量。照片转 3D 与淘宝 / 京东任务自动化仍未实现。

## 角色路线与启动设置

- 形象库新增天使系四形态及成年女性四套造型，三条路线共用经验、已解锁上限和记忆。完成四阶段后可自由切回全部四种形象。
- 成年角色的基础网格来自 MakeHuman CC0 图形资产，不使用其 AGPL 程序代码。来源、固定提交与许可见 public/avatars/ATTRIBUTION.txt 和 licenses/MAKEHUMAN-ASSETS-CC0.md。分发的是着装基础网格，不分发原始 OBJ 和辅助网格。不是个人扫描或一比一还原。
- 女性造型均为成年人，无幼年或未成年形态。支持服装、发型和外搭更换，基础服装始终保留。
- Windows 开机自启默认关闭，仅用户开启后调用系统登录项设置。请保留便携版目录，移动后应重新设置。Linux 和开发运行不修改系统登录项。
- 安卓后台常驻默认关闭，使用同一个前台服务和常驻通知，不添加唤醒锁、定时保活或开机广播。关闭悬浮窗但保留后台常驻时销毁 WebView，不渲染 3D。通知栏可停止后台陪伴。
- 后台常驻不能保证不被 Android / 小米系统回收；提供应用省电和小米自启动设置入口，由用户自行设置。
- Windows 引擎可复用成功的原生构建 38844003853：校验安装 ZIP SHA-256、固定源码提交、静态运行库、CPU 兼容参数和引擎文件校验和，重新执行包内推理后分发。
